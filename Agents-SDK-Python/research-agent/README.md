# Research Agent

An AI agent that searches for information and synthesizes it into comprehensive reports.

## Features

- 🔍 **Web Search**: Searches the internet for current information
- 🔗 **Source URLs**: Appends unique links from the API's `url_citation` annotations
- 📝 **Synthesis**: Combines findings into structured reports
- ⚠️ **Verification**: Does not independently check source reliability or guarantee support for every claim

## Usage

```bash
pip install -r requirements.txt
python main.py
```

The final source list is built from API citation metadata, not generated by the synthesizer. If the search responses contain no URL citations, the report states that explicitly. Verify claims before relying on the report.

## Example Queries

```
"Research the latest developments in fusion energy"
"Compare React vs Vue for enterprise applications"
"What are the health benefits of intermittent fasting?"
```

## How It Works

```
User Query
    ↓
┌─────────────┐
│ Query       │ ← Break down into sub-questions
│ Planner     │
└──────┬──────┘
       ↓
┌─────────────┐
│ Research    │ ← Search web, evaluate sources
│ Tool        │
└──────┬──────┘
       ↓
┌─────────────┐
│ Synthesizer │ ← Combine and format
└──────┬──────┘
       ↓
  Final Report
```
